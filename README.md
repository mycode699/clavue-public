# Clavue Public Distribution

Public distribution artifacts for Clavue (v1 alongside historical v8).

## Install clavue-v1 (recommended)

```bash
curl -fsSL https://raw.githubusercontent.com/mycode699/clavue-public/main/install.sh | bash
```

Pin:

```bash
curl -fsSL https://github.com/mycode699/clavue-public/releases/download/v1.63.0/install.sh | bash -s -- 1.63.0
```

npm fallback:

```bash
npm install -g clavue-v1@1.63.0
```

Current release: **1.63.0** — window-cut notes reject system-reminder chrome and continuation-only goals; the default archive hard cut is 32MB; `/rewind` stays populated after a cut. Absolute Full Access unchanged.

The installer resolves the highest **v1.*** release via the GitHub API (never `/releases/latest`, which may still point at v8).

## Legacy clavue (v8)

```bash
npm install -g clavue
```
